# eMAG ПЦД ≥ 50% — автоматичен скенер

Това е **начална реална реализация**, не гаранция, че emag.bg позволява обхождане: няма заобикаляне на антибот защити, логин, проксита или CAPTCHA. Ако robots.txt е недостъпен/забранява, скенерът **не обхожда**. Търси **сайтови карти** и продуктовите адреси (`/pd/`), които открива там. Това **не гарантира всички категории**; няма гаранция за продуктови sitemap-и или ПЦД в HTML. Сървърният HTML може да не съдържа цени, които се виждат в браузъра.

## Пускане само от Android

1. Отвори https://github.com и влез/създай безплатен акаунт.
2. Създай **публично** repository `emag-pcd`.
3. Качи **съдържанието** на ZIP-а в корена на repository (GitHub уеб интерфейсът може да изисква да качваш файлове поотделно; `.github/workflows/scan.yml` трябва да запази точно тази директория). Най-удобно е през GitHub web интерфейс с Desktop site или Git клиент на Android.
4. Settings → Pages → Build and deployment → **Source: GitHub Actions**.
5. Actions → Scan public eMAG sitemaps → **Run workflow**.
6. След приключване виж `https://ТВОЯ-ПРОФИЛ.github.io/emag-pcd/`.
7. Всеки ден около 03:23 UTC системата опитва сканиране. Графикът на GitHub може да се забави или изключи при 60 дни без активност.

## Ограничения

- robots.txt се изисква за всяко стартиране; при блокировка отчетът показва `access_blocked`. Проверката не доказва, че всяко извличане е разрешено по условията за ползване.
- Лимит по подразбиране: 150 продукта/сканиране, 40 sitemap файла, 5 секунди между заявки, без обход при 401/403/429/503/511.
- За повече продукти увеличи `MAX_PRODUCTS` предпазливо само при разрешено и стабилно обслужване.
- Резултатите са само за открити и проверени продуктови адреси с изрично ПЦД в HTML и надеждна цена във валута; неизвестните се пропускат.
- Всичко е публично в GitHub Pages. Няма потвърдени реални резултати към датата на изготвяне.
- ПЦД е препоръчителна цена, не доказателство за реална историческа отстъпка.
